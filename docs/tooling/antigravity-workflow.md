# Trợ lý lập trình Antigravity

Mở workspace tại thư mục gốc và giao việc theo [quy trình chung](../../README.md#quy-trình-chung). Các quy ước nằm trong [AGENTS.md](../../AGENTS.md). [Quy tắc workspace](../../.agents/rules/01-agent-behavior.md) trỏ về cùng tài liệu. [Tài liệu Rules](https://antigravity.google/docs/rules)

Trong Antigravity App hoặc CLI tương tác, nhập `/<tên-skill>` để chọn một quy trình từ [.agents/skills/](../../.agents/skills/).

| Lệnh | Dùng khi |
| --- | --- |
| `/project-bootstrap` | Khởi tạo dự án và ghi các quyết định công nghệ. |
| `/spec-to-architecture` | Soạn yêu cầu, kiến trúc và các đặc tả liên quan. |
| `/issue-driven-dev` | Triển khai một Issue hoặc Task Contract. |
| `/impeccable-ui-workflow` | Thiết kế và rà soát giao diện. |
| `/verify-dod-and-pr` | Chạy kiểm chứng và chuẩn bị bàn giao. |

Nếu phiên không hiển thị lệnh mong muốn, chỉ định đường dẫn đến `SKILL.md` trong lời nhắn. Khi phân công việc, chọn vai trò mà phiên hỗ trợ và dẫn [hồ sơ vai trò dùng chung](../../.agents/agents/) để thống nhất phạm vi. [Tài liệu Agent skills](https://antigravity.google/docs/skills)
